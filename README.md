# Цикл — трекер циклов

Личное веб-приложение: карточки девушек, календарь месячных, прогноз овуляции, фертильного окна и ПМС, отметки близости, заметки и общая сводка на 7 дней вперёд.

Стек: Next.js (деплой на Vercel) + Upstash Redis (бесплатная облачная база). Аккаунтов нет.

---

## Деплой за ~10 минут

### 1. Залить код на GitHub
1. Зарегистрируйся на [github.com](https://github.com), нажми **New repository**, назови, например, `cycle-tracker`, сделай его **Private**, создай.
2. На странице пустого репозитория нажми **uploading an existing file**.
3. Распакуй архив и перетащи **содержимое папки** `cycle-tracker` (файлы `package.json`, папки `app`, `lib`, `components` и т.д.) в окно браузера. Папку `node_modules` перетаскивать не нужно — её и нет в архиве.
4. Нажми **Commit changes**.

### 2. Задеплоить на Vercel
1. Зайди на [vercel.com](https://vercel.com) через GitHub.
2. **Add New → Project**, выбери репозиторий `cycle-tracker`, нажми **Deploy**. Ничего не меняй — Vercel сам поймёт, что это Next.js.
3. Через минуту сайт заработает. Сверху будет плашка «База не подключена» — данные пока живут только в браузере. Это нормально, подключаем базу.

### 3. Подключить бесплатную базу
1. В проекте на Vercel открой вкладку **Storage**.
2. **Create Database** → выбери **Upstash** → **Redis** (Serverless Redis).
3. Тариф — **Free**, регион — ближайший (например, Frankfurt). Создай.
4. Vercel спросит, к какому проекту подключить — выбери `cycle-tracker`, оставь все окружения (Production, Preview, Development).
5. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
6. Вкладка **Deployments** → у последнего деплоя три точки → **Redeploy**.

Готово: плашка исчезнет, данные будут в облаке и одинаковые на телефоне и компьютере. Бесплатного лимита Upstash для одного человека хватит с огромным запасом.

> Если делал записи до подключения базы — при первой загрузке они автоматически уедут в облако с того же браузера.

### 4. Поставить PIN (очень советую)
Адрес сайта на Vercel публичный — любой, кто его узнает, увидит данные. Чтобы закрыть:
1. Vercel → проект → **Settings → Environment Variables**.
2. Добавь переменную `APP_PIN` со значением, например `4821`.
3. **Redeploy**.

Теперь сайт спросит PIN один раз на каждом устройстве.

### 5. Иконка на телефоне
Открой сайт в Safari/Chrome → «Поделиться» → **На экран «Домой»**. Будет открываться как приложение.

## Как пользоваться
- **+ Карточка** — имя, цвет и (если знаешь) дата начала последних месячных.
- В карточке нажми на любой прошедший день в календаре: «Начались месячные», «Закончились в этот день», «Отметить близость».
- Чтобы прогноз стал точным, отметь 2–3 прошлых начала месячных, если помнишь даты.
- На главной — сетка на 7 дней по всем и список событий: у кого месячные, овуляция, фертильное окно, ПМС.
- **Скачать бэкап** внизу главной — JSON-файл со всеми данными на всякий случай.

## Как считается прогноз
- Длина цикла: пока истории нет — значение из настроек карточки (по умолчанию 28 дней). С 1–2 циклами — среднее, смешанное с этим значением. С 3+ — взвешенное среднее последних 6 циклов (свежие весят больше).
- Овуляция — за 14 дней до следующих месячных.
- Фертильное окно — 5 дней до овуляции, день овуляции и день после.
- ПМС — 5 дней перед месячными.
- Если месячные опаздывают (до 14 дней) — показывается «Задержка N дней».
- «Точность» растёт с количеством отмеченных циклов и падает, если циклы скачут.

Это оценка по среднему, а не медицинский прогноз и не метод контрацепции.

## Локальный запуск (необязательно)
```bash
npm install
npm run dev
```
Открыть http://localhost:3000. Без переменных базы приложение работает в режиме «только в браузере».
